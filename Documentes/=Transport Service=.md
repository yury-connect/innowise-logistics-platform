## **Transport Service**
### Задачи:
- реестр водителей;
- назначение водителей на транспортные средства (ТС); 
- реестр ТС;
- графики ТО TC;
### Особенности:
- Высокая нагрузка (работа с множеством заказчиков);
- Масштабируемость / Лекговесность;
- Если происходит ЧП с транспортом - то уведомляет сервис доставки;
- Все протоколирует в Reporting Service;
### Стек:
- DB: Postgres;
- Kafka;

---
### Транспортные средства (ТС):
- Добавить новый ТС в автопарк предприятия;
- Получить информацию о ТС/ получить все ТС с пагинацией и без;
- Изменить статус ТС;
  - по занятости (занят в перевозке/ свободен для приема доставки)
  - по тех. состоянию (исправен/ неисправен/ на обслуживании/ в ремонте)
- Удалить ТС из автопарка;

### Водители
- Добавить нового водителя
- Получить информацию о водителе/ всех водителей с пагинауией и без;
- Изменить:
  - Прикрепить/ открепить ТС к данному водителю (у водителя может быть несколько ТС);
  - Статус водителя (работоспособен/ болен-на больничном/ на выходном/ временно неработоспособен)
- Удалить водителя;

### График Тех. обслуживания ТС
- назначить на какой-то день ТО ТС, в этот день данное ТС будет недоступно для бронирования в доставку. Назначается дата в список занятых дат. Передается List занятых дат, можно по одной;
- освоболить ТС от ТО на заданную дату
- получить список:
  - дат ТО для заданного ТС;
  - доступных дат для заданного ТС;
  - список ТС, занятых в ТО на данную дату;
  - список ТС, свободных от ТО на данную дату;
  - количество ТС, занятых в ТО на заданную дату;
  - количество ТС, свободных от ТО на заданную дату;
  - когда было ТО (последнее ТО) данного ТС;
  - когда планируется ТО данного ТС;
- освободить данное ТС от всех ТО;

## Назначение водителя:
**Бизнес - правила:** 
- На конкретное заданное может быть назначен только один водитель. 
	  т.е. назначить более 1 водителя на 1 ТС невозможно. 
- На одного водителя может быть назначено только 1 ТС каждого вида.
	  т.е. водитель может зарезервировать на себя 1 грузовой автомобиль, 1 легковой
	  бронирование более 1 ТС каждого вида запрещено

| Метод  | Эндпоинт                                           | Описание                                                                       | Роль                                              |
| ------ | -------------------------------------------------- | ------------------------------------------------------------------------------ | ------------------------------------------------- |
| PUT    | `/api/v1/transports/{transportId}/assign`          | Привязать пользователя к ТС (см. тело запроса). Возвращает объект назначения.  | `SUPERVISOR` (любого)                             |
| PUT    | `/api/v1/transports/{transportId}/current-user`    | Привязать текущего пользователя к ТС (без тела). Возвращает объект назначения. | `DRIVER` (только себя), <br>`SUPERVISOR` (любого) |
| DELETE | `/api/v1/transports/{transportId}/assign/{userId}` | Отвязать пользователя от заданного ТС. Тела ответа нет.                        | `DRIVER` (только себя), <br>`SUPERVISOR` (любого) |
| DELETE | `/api/v1/transports/{transportId}/assign`          | Отвязать текущего пользователя от заданного ТС. Тела ответа нет.               | `DRIVER`, <br>`SUPERVISOR`                        |
| GET    | `/api/v1/transports/{transportId}/assign`          | Узнать, какой пользователь назначен на заданно ТС. Ответ: id пользователя      | `DRIVER` (только себя), <br>`SUPERVISOR` (любого) |
| GET    | `/api/v1/transports/drivers`                       | Список водителей (для назначения). Ответ: список id пользователей              | `SUPERVISOR`                                      |
| GET    | `/api/v1/transports/transports`                    | Список ТС (для назначения). Ответ: список id ТС                                | `DRIVER`, `SUPERVISOR`                            |

**Тело запроса:**
```json
{
  "userId": "1_234_567"
}
```

Объект назначения.
```json
{
  "userId": "1_234_567",
  "role": "DRIVER",
  "transportId": "1_234"
  "assignedAt": "2026-05-06T10:00:00Z"
}
```

**Ответы:**
- `200 OK` — назначение выполнено (или уже было выполнено ранее)   
- `404 Not Found` — транспорт не найден    
- `409 Conflict` — транспорт уже занят (если нельзя пересаживать)    
- `400 Bad Request` — пользователь не существует (если Transport service проверяет)

**Авторизация:**
- `DRIVER` может назначить **только себя** (`userId` из его токена)    
- `SUPERVISOR` может назначить **любого пользователя**
