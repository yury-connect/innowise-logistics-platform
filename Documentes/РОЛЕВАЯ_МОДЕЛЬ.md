# Описание ролевой модели платформы

---
**Бизнес-правило**:
- 1 пользователь может иметь только 1 роль.
	  т.е. роль - это не список, а константа.

---
### Пояснение ролей в системе:
**ADMIN** - полный контроль над системой;
**SERVICE** - для межсервисного взаимодействия;
**BANK** - банковская система только она может вернуть оплаченный счет;
**MANAGER** - наполнение склада, все операции по складу;
**USER** - базовые операции;
**DRIVER** - только он может менять статус автомобиля;
